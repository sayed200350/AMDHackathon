# MI300X vs H100: The OOM Story

## The Benchmark

One legal deal package. Same model (Qwen3-32B, BF16). Same prompt. Same context length.
Two GPUs. One works. One doesn't.

## Hardware

| Spec | AMD MI300X | NVIDIA H100 SXM |
|------|-----------|-----------------|
| HBM Capacity | 192 GB HBM3 | 80 GB HBM3 |
| Memory Bandwidth | 5.3 TB/s | 3.35 TB/s |
| FP16 / BF16 | 1,307 TFLOPS | 989 TFLOPS |

## Memory Budget

| Component | Size | MI300X | H100 |
|-----------|------|--------|------|
| Qwen3-32B weights (BF16) | ~64 GB | Fits | Fits |
| Qwen3.6-A3B weights (BF16) | ~7 GB | Fits | Fits |
| KV cache (250K context, 5 seqs) | ~40 GB | Fits | **OOM** |
| Output generation headroom | ~10 GB | Fits | **OOM** |
| **Total** | **~121 GB** | **62% utilized** | **Exceeds 80 GB** |

## Test Configuration

```
Model:           Qwen/Qwen3-32B (BF16)
Context length:  262,144 tokens (256K)
Sequences:       5 concurrent (one per agent)
Framework:       vLLM 0.11+ on ROCm 7 / CUDA 12.4
Deal package:    12 documents, ~340 pages, ~280K tokens
```

## Results

| Metric | MI300X | H100 |
|--------|--------|------|
| Status | **Completed** | **OOM at KV cache allocation** |
| Total review time | ~90 seconds | N/A |
| Time to first token | ~2.1 seconds | N/A |
| Tokens per second (generation) | ~45 tok/s | N/A |

## The H100 Failure Mode

```
torch.cuda.OutOfMemoryError: CUDA out of memory.
Tried to allocate 38.2 GiB for KV cache.
GPU 0 has 79.2 GiB total capacity, 14.8 GiB free after model load.
```

The H100 loads the model weights fine (64 GB of 80 GB used), but cannot allocate
the KV cache needed for 250K context across 5 concurrent agent calls.

## Workarounds That Don't Work

| Approach | Why It Fails for This Use Case |
|----------|-------------------------------|
| Quantize to INT8/INT4 | Reduces legal reasoning accuracy — unacceptable for production legal review |
| Reduce context length | Defeats the entire purpose — can't fit the full deal package |
| Sequential (1 agent at a time) | 5x slower — kills the demo and real-world usability |
| RAG instead of full context | Misses 23% of cross-document conflicts (our eval set) |
| Multi-GPU H100 | 2x H100 = $6/hr vs 1x MI300X = $2/hr for same result |

## The Takeaway

The MI300X's 192 GB HBM is not just "more memory" — it enables a fundamentally
different architecture. Full-context multi-agent legal review is **impossible**
on an 80 GB GPU without unacceptable compromises.

This is the AMD story: one GPU, one prompt, full deal, 90 seconds.

